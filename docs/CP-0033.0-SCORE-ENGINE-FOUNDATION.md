# CP-0033.0 — Score Engine Foundation

Implements traditional side-out scoring.

Supported:
- doubles
- singles
- only serving side scores
- doubles first/second server sequence
- special first service sequence
- side-out
- serving court parity
- configurable target score
- win-by-two
- game winner

Default doubles opening score call:
0-0-2

Input:
Trusted RALLY_WON results from CP-0032.

This capability does not yet implement rally scoring.
A later CP-0033.x capability can add a separate rally-scoring strategy.
