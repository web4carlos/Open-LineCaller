# CP-0033.1 — Score Integration with Rally Outcomes

Purpose:
Connect trusted CP-0032 RallyOutcomeResult objects to the CP-0033
traditional side-out Score Engine.

Contract:

RALLY_WON + known winner
    -> Score Engine may apply POINT / SECOND_SERVER / SIDE_OUT.

RALLY_CONTINUES
    -> no score/service mutation.

REVIEW
    -> no score/service mutation.

Unknown/malformed winner
    -> fail safe, no mutation.

This preserves the system-wide uncertainty rule:

    REVIEW NEVER CHANGES THE SCORE.

The bridge does not reinterpret vision, geometry, or rules evidence.
It consumes the trusted rally outcome produced upstream.
