# CP-0034.1 — Python ↔ React Live Bridge

Adds a dependency-light local HTTP bridge on 127.0.0.1:8765 and React polling primitives.
The bridge exposes immutable facility/court snapshots. This CP proves the transport boundary;
later CPs feed the store from the real officiating pipeline instead of demo seed data.

Endpoints:
- GET /api/health
- GET /api/live
- GET /api/courts/{court-id}
