# CP-0006 Validation Plan

For each real video record:

- source resolution
- source FPS
- camera angle
- indoor/outdoor
- detector candidate count
- tracked frames
- predicted frames
- lost frames
- bounce events
- IN / OUT / REVIEW counts

Ground-truth validation must additionally record:

- manually labeled bounce frame
- manually labeled call
- bounce frame error
- decision agreement

The next capability will automate these comparisons.
