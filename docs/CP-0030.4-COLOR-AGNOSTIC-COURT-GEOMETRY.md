# CP-0030.4 — Color-Agnostic Court Geometry Refinement

Principle:

> A line is not a pickleball court line because of how it looks.
> It becomes one because of how it fits the complete pickleball court geometry.

The refinement stage does not require white paint. It uses multi-channel
contrast edges around the expected court geometry, fits boundary candidates,
intersects them, and accepts the refinement only when measured support improves.

The original calibration is retained when improvement cannot be demonstrated.
