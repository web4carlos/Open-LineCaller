# CP-0033.4 — Integrated Match Scoring Pipeline

Final CP-0033 orchestration layer.

Input:
Trusted CP-0032 RallyOutcomeResult.

Pipeline:

RALLY OUTCOME
      |
RALLY -> SCORE BRIDGE
      |
POINT / SECOND SERVER / SIDE-OUT
      |
GAME LIFECYCLE
      |
MATCH LIFECYCLE
      |
HISTORY + ANNOUNCER STATE

Key guarantees:
- REVIEW never changes score.
- RALLY_CONTINUES never changes score.
- completed games are committed automatically.
- a completed match rejects later scoring mutations.
- every input event is auditable in score history.
- UI/TTS consumers receive one announcer snapshot.

This closes the core CP-0033 traditional scoring architecture.
