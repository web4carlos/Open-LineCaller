# CP-0014D User Guide

Mark reliable frames as Keyframes.

Then use batch/range assistance to generate proposals between keyframes.

Recommended workflow:
1. annotate a clear frame
2. mark it as keyframe
3. jump 10-20 frames
4. annotate another keyframe
5. use propagation between them
6. inspect REVIEW/REJECT proposals
7. accept only correct boxes

Confirmed boxes are protected.
