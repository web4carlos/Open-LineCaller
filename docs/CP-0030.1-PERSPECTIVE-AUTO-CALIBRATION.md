# CP-0030.1 — Perspective Auto Calibration

Problem found on MATCH001:
The initial auto calibrator looked for nearly vertical sidelines.
In an end-court camera perspective, actual sidelines are diagonal.

Fix:
- horizontal candidates remain baseline candidates
- 20–70 degree diagonal lines become sideline candidates
- left/right sideline families are separated by perspective direction
- sidelines are projected onto near/far baselines
- perspective sanity checks reject bad quadrilaterals

AUTO remains the default option.
MANUAL remains the safe fallback.
