# CP-0019.1A User Guide

## Step 1 — Create ground truth

Use Validation Lab:

    .\.venv\Scripts\python.exe -m tools.validation_lab

Mark real bounce events as IN or OUT and save:

    ground_truth.jsonl

## Step 2 — Run automatic offline validation

    .\.venv\Scripts\python.exe -m tools.offline_validation_runner `
      --video C:\validation\match01.mp4 `
      --ground-truth C:\validation\ground_truth.jsonl `
      --predictions C:\validation\predictions.jsonl `
      --report C:\validation\report.json

## Step 3 — Read results

The console prints:
- automatic accuracy
- coverage
- review rate
- miss rate
- false IN
- false OUT
- source FPS
- effective processing FPS

## Important

A good offline result does not prove the live product works.

CP-0019.1B will validate the live camera path separately.
