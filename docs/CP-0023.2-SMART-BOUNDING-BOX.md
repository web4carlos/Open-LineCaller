# CP-0023.2 — Smart Bounding Box

Workflow:

    click near pickleball
    -> local ROI
    -> yellow/yellow-green + brightness search
    -> adaptive rectangular bbox
    -> zoom preview
    -> SPACE accepts
    -> next frame

The helper stays local to the click. It is not an autonomous detector.

If no suitable candidate is found, it safely falls back to the user's click
with the previous default-size box.

Existing CP-0023.1 sessions migrate automatically.
