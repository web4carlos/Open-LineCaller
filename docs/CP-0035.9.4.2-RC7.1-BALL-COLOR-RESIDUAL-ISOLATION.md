# CP-0035.9.4.2 RC7.1 — Ball-Color Residual Isolation

## Purpose
RC7 proved that `PIL.ImageChops.difference(current, background)` retains foreground evidence at the user-confirmed same-ball locations, but the raw residual was visually noisy.

RC7.1 isolates the ball-colored portion of that residual without hard-coding a color name.

## Contract

`CURRENT - BACKGROUND -> RAW RESIDUAL`

`RAW RESIDUAL ∩ LOCKED BALL COLOR PROFILE -> BALL RESIDUAL`

The locked color profile is learned from the runtime ball reference. It is not a constant such as yellow, orange or green.

## Strict responsibility split
- Ball identity / color profile: WHO evidence.
- PIL residual: foreground change evidence.
- RC7.1 isolation: compact same-ball residual evidence.
- P(x,y,z,t): separate spatial/time state.
- Rolling three-point predictor: separate Z0 math.

RC7.1 does **not** define XYZ, velocity, path, or Z0.

## Production visibility
None. The four-panel visualization is an engineering gate only.
