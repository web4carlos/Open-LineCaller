# CP-0034.4a — CSV Officiating Timeline Adapter

The validated LineCaller workflow currently produces CSV artifacts.

For the real match001 validation chain, the strongest downstream artifact is:

`cp0029-1-final-officiating-v2/final_officiating_decisions.csv`

It already contains:
- bounce frame
- image x/y
- court geometry
- nearest line
- signed distance
- base decision
- decision confidence
- bounce officiating gate
- force_review
- final_decision
- officiating reason

Therefore CP-0034.4a consumes that artifact directly.

Important invariant:

`force_review=True` must publish `REVIEW`, never a terminal IN/OUT call.

React does not derive or reinterpret the call. It only synchronizes the
validated final decision to the video frame.
