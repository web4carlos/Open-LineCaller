# CP-0036.2.4.6.1 — Perspective Ball-Scale Bootstrap Guard

## Real-video finding

After CP-0036.2.4.6, Top-3 was active but bootstrapped the wrong trajectory:

- TRACK LOCK: BOOTSTRAP
- TRACK DEPTH: 4
- TRACK PREDICTED XY: about (246.4, 168.0)
- TRACK GATE: 66.50 px
- TOP-3 XY: about (246.3, 168.0)

Because the continuity gate is 4.75 * component scale, a 66.50 px gate implies
the locked component was about 14 px wide. That is far larger than the
perspective-projected pickleball scale in that image region.

## Change

Bootstrap now has continuous perspective scale evidence from the court
homography. It maps each image component to continuous court coordinates and
projects one Ball Unit laterally at that point to estimate the expected
pickleball diameter.

This does NOT construct, traverse, or use an interior decision grid.

Only bootstrap candidates whose observed scale is compatible with this
continuous expected diameter may create the trajectory lock.

Bootstrap scale bounds are intentionally more tolerant than official contact
scale:

- minimum ratio: 0.35
- maximum ratio: 2.20
- existing tiny-ball +/-0.5 px raster tolerance applies below 3 px expected

The official Z0 floor-scale gate remains unchanged at 0.45-1.80.
