# CP-0036.2 - Video-First LineCaller Wizard

Status: IMPLEMENTED

## Goal

Use a real pickleball video as the primary development/test source before
requiring a physical court and live camera.

The decision engine remains exactly the same:

`OfficialExternalLiveRuntime`

Only the frame source changes.

## Default flow

1. Upload a pickleball video in the browser.
2. Browse with Play/Pause, scrubber, or Step Frame.
3. Stop on a clean court frame.
4. Capture that frame as the calibration background.
5. Click the four OUTER court corners:
   - near-left;
   - near-right;
   - far-right;
   - far-left.
6. Build the OFFICIAL outside-only grid.
7. Seek to a frame with a clearly visible ball.
8. Arm ball selection and click the ball center.
9. Configure camera ownership / receiving side.
10. Analyze the video deterministically frame-by-frame.

## Video stays in the browser

CP-0036.2 does not upload the full video to FastAPI.

The HTML video element decodes the local file. The canvas captures the current
frame and sends only that image to the existing `/api/live/frame` endpoint.

This means the video path uses the same API contract as the live camera path.

## Deterministic analysis

Normal video playback may skip frames when backend processing is slower than
the video frame rate.

For engineering analysis, `Analyze Video Frame-by-Frame` pauses normal
playback and advances:

`currentTime += 1 / Analysis FPS`

only after the current image has been processed.

This gives LineCaller the ordered frame sequence needed for:

- ball continuity;
- Z0 candidate;
- UP-after-the-fact;
- OUT confirmation;
- glow.

The default analysis rate is 30 FPS and can be adjusted to match the source
video.

## Manual transport

Before or during debugging:

- Play/Pause;
- timeline scrubber;
- Step Frame backward;
- Step Frame forward;
- Go to Start;
- Process Current Frame.

This makes a suspect bounce repeatable.

## Camera fallback

`Live Camera` remains available and still uses
`navigator.mediaDevices.getUserMedia()`.

The normal development recommendation is video first, live camera second.

## Outside-grid invariant

Nothing in CP-0036.2 creates or scans an interior grid.

Calibration continues through `ExternalGridCalibrator`.
Runtime continues through `OfficialExternalLiveRuntime`.
Camera ownership remains fail-closed.
Pose Guard remains before the external scan.
