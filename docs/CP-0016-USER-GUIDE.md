# CP-0016 User Guide

## Start

    cd C:\olinecaller
    .\.venv\Scripts\python.exe -m tools.live_match_app

## Flow

1. Select camera
2. Check calibration status
3. Press START MATCH
4. Watch live preview
5. IN / OUT calls appear in the call banner
6. REVIEW opens replay mode
7. Developer Diagnostics can be enabled for testing

## Notes

This is the Windows development version of the final mobile experience.
