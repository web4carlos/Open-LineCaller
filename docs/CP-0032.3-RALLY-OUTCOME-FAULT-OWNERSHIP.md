# CP-0032.3 — Rally Outcome + Fault Ownership

Purpose:
Translate trusted terminal rules events into explicit rally ownership.

Outputs:
- RALLY_CONTINUES
- RALLY_WON
- REVIEW

Terminal event ownership supports:
- ball OUT
- serve fault
- two-bounce fault
- NVZ fault
- double bounce
- other explicit faults

Core safety invariant:
REVIEW cannot produce a rally winner.

This capability deliberately does NOT modify the score.
It only determines who won/lost the rally and why.

CP-0033 will consume these trusted rally outcomes to implement scoring.
