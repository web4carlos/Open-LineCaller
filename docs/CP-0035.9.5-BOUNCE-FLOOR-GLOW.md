# CP-0035.9.5 — Bounce Floor Glow

Baseline: **CP-0035.9.4.1 / fdef013**.

This capability is presentation only. It does not detect the ball, infer a bounce,
or classify IN/OUT/REVIEW.

## Contract

`BallWaveTracker` remains authoritative. The floor may illuminate only when:

- `BallWaveStep.floor_trigger == True`, and
- `BallWaveStep.predicted_contact_cell` exists on `Z=0`.

This supports both the strict `Z=1 + DOWN -> predicted Z=0` rule and a directly
accepted descending `Z=0` cell.

## Production visibility

The DCF, mesh, Ball Wave, candidate cells, coordinates, boxes and technical cell
polygon remain invisible. The user sees only a soft perspective-correct floor
footprint centered on the contact location.

The visible footprint uses DCF-cell units (one cell ~= one pickleball diameter),
but it is rendered as a feathered disc/halo, never as a technical square.

## Timing

- fade in: 180 ms
- hold: 1400 ms
- fade out: 900 ms
- total: 2480 ms

## Color

Color is supplied at runtime. Decision-to-color mapping is intentionally deferred
to the next decision-visual capability.
