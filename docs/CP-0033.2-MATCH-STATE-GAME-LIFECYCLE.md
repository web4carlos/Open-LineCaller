# CP-0033.2 — Match State + Game Lifecycle

Adds a match-level controller above the point/service Score Engine.

Responsibilities:
- best-of-N match structure
- games required to win
- commit a completed game
- games A/B counters
- start a fresh point/service engine for each new game
- optional alternating starting team between games
- match winner
- protection against committing unfinished games
- protection against modifying a completed match

Layering:

CP-0032 Rally Outcome
        |
CP-0033.1 Rally -> Score Bridge
        |
CP-0033.0 Point / Service Score Engine
        |
CP-0033.2 Match Controller
        |
GAME / MATCH STATE

This capability uses target_score=11 and win_by=2 by default, but tests use
short games for deterministic speed.
