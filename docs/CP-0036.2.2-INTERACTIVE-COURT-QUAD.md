# CP-0036.2.2 - Interactive Court Quad

Status: IMPLEMENTED

After `Capture Clean Court`, LineCaller places four draggable handles:

- NL - near-left
- NR - near-right
- FR - far-right
- FL - far-left

The operator drags the handles until the blue quadrilateral follows the outer
court boundaries and presses `Confirm Court & Build Outside Grid`.

A mathematical court corner may be off-screen. The coordinate can remain
outside the image while an edge proxy remains visible and is labeled `OFF`.

The backend accepts reasonable off-screen handle positions, but rejects
implausibly distant corners, crossed quadrilaterals and degenerate geometry.

`Boundary Lines` and `4 Visible Corners` remain available under Advanced
calibration tools.

Interactive Quad does not create another grid implementation. Confirmed
corners are passed into the existing `ExternalGridCalibrator`, so operational
LineCall cells remain outside-only and all existing ownership/Pose Guard
runtime gates remain unchanged.

Automatic line fitting can later improve the initial handle proposal without
changing this manual confirmation contract.
