The game must NOT loop over every external cell.

that can matter for that side:

- FAR: far baseline band + far-half left/right sideline bands.
- NEAR: near baseline band + near-half left/right sideline bands.

Then every frame runs:

`FRAME -> PILLOW(calibrated reference) -> ACTIVE EXTERNAL AREA`

No ball tracker, no path, no XYZ, no DOWN, and no BINGO in this gate.
