# CP-0035.5 — Real Ball -> DCF Continuity Gate

Purpose:
Bridge existing real `ball_track.csv` data into the DCF architecture without
modifying the production YOLO/Kalman/Bounce pipeline.

The capability:
- consumes real tracker samples,
- predicts the next plausible image-space position from recent accepted motion,
- rejects impossible identity jumps,
- preserves the existing lock after a rejected candidate,
- writes a diagnostic CSV,
- reports identity-jump frames.

This is the first real-data Ball Identity Gate.

It deliberately does NOT infer Z yet.
It deliberately does NOT produce IN/OUT yet.
It deliberately does NOT modify the existing tracking pipeline.
