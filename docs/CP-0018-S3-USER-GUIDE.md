# CP-0018 Sprint 3 User Guide

From Start Match:

1. Select Camera
2. Complete Calibration
3. Run System Check

The app will report:

- Camera
- Calibration
- Replay
- Audio
- Tracking
- FPS
- Latency
- Storage

If a check fails, a suggested recovery action is shown.

Only when required checks pass does the wizard move to READY.
