# CP-0030.5 — Global Pickleball Geometry Fitting

Core principle:

> A line is not a pickleball court line because of how it looks.
> It becomes one because of how it fits the complete pickleball court geometry.

CP-0030.4 proved that local edge support can improve while still selecting the
wrong physical boundary.

CP-0030.5 therefore scores a complete court hypothesis using:
- both baselines
- both sidelines
- both NVZ lines
- net-axis geometry
- both centerline segments

Interior pickleball geometry receives additional weight to reject nearby
tennis or multisport rectangles.

Color is not a requirement. Multi-channel contrast supplies visual evidence.

The fitter does not overwrite the accepted calibration. It writes a candidate
JSON for visual validation.
