# CP-0032.0 — Pickleball Rules Engine Foundation

Purpose:
Establish the deterministic rally-state layer that consumes trusted
officiating events.

Architecture:

VISION
-> EVIDENCE
-> GEOMETRY
-> DECISION
-> RULES

Core invariant:
The Rules Engine may interpret a trusted decision, but it may never upgrade
REVIEW uncertainty into an automatic IN or OUT call.

CP-0032.0 provides:
- rally lifecycle
- serving/receiving team state
- serve/return/third-shot/open-rally phases
- bounce and hit counters
- fault/end-rally handling
- chronological event protection
- REVIEW propagation

Later CP-0032.x capabilities add:
- serve legality
- two-bounce rule
- NVZ/kitchen rules
- fault ownership
- rally winner determination
