# CP-0036.1.1 - Numeric Stability Resume

Status: REPAIR CONTINUATION

The strict quality gate correctly stopped CP-0036.1.1 with one remaining
historical flight-path failure:

`test_gravity_is_compensated_before_comparing_velocity`

Observed angle:

`1.2074182697257333e-06 degrees`

Required:

`< 1e-06 degrees`

The candidate itself was correctly classified as `TransitionKind.NONE`.
The discrepancy came from computing a near-zero vector angle through
`acos(dot / (|a||b|))`, which is ill-conditioned near cosine = 1.

The implementation now uses:

`atan2(|a x b|, a . b)`

This is the standard stable vector-angle formulation near both 0 and pi and
does not loosen the existing test tolerance.

The repair is released only after the strict full repository quality gate
passes before commit/push.
