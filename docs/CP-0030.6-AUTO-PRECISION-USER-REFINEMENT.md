# CP-0030.6 — Auto + Precision User Refinement

Product rule:

AUTO is the first option.
AUTO does not need to pretend it is perfect.

Flow:
AUTO -> full-court preview -> ACCEPT or ADJUST -> ACCEPT.

The user may:
- drag any of four large corner handles;
- drag any of the four OUTER boundaries;
- undo;
- reset to the original AUTO result;
- accept with Enter;
- cancel with Escape.

Interior pickleball lines are never independently deformed.
NVZ lines, centerlines and net are always recomputed from the same valid
20 x 44 ft pickleball homography.

Saved calibrations identify themselves as:
AUTO_USER_REFINED

This preserves both usability and geometric integrity.
