# CP-0026.1 — Bounce Validation

This refinement reduces false bounce events.

A bounce now requires:

1. downward motion before the candidate,
2. upward motion after the candidate,
3. candidate near the local maximum image-y,
4. horizontal continuity,
5. enough RAW observation support,
6. minimum composite confidence,
7. refractory period.

Reminder:
Image Y increases downward, therefore the floor-contact point is expected near a
local MAXIMUM of image Y.

No IN/OUT decision is added in this pack.
