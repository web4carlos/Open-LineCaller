# CP-0036.2.5 — Dual Net-Mount Half-Court Foundation

## Product topology

LineCaller v1 is designed around two ordinary phones mounted on the net:

- Phone A watches one half-court.
- Phone B watches the other half-court.
- Each phone has its own calibration, background and ball selection.
- Each phone owns only LEFT sideline + BASELINE + RIGHT sideline of its local half.
- The area beyond the net belongs to the other phone.

No phone is expected to hang above the court.

## Production geometry

For a true HALF_COURT net-mounted calibration, local court coordinates are:

- x=0..83 BU: sidelines
- y=0 BU: baseline
- y=91 BU: net edge

The production external area includes:

- HALF_LEFT
- HALF_BASELINE
- HALF_RIGHT

External cells beyond the net edge are excluded.

## Full-court engineering compatibility

The existing broadcast reference video remains useful for regression testing.
When a FULL_COURT calibration is loaded, CP-0036.2.5 does NOT call it production
half-court mode. Instead the bootstrap trajectory is constrained to the selected
receiving half using the continuous homography.

This directly rejects the observed regression:

- wrong lock floor Y = 200.64 BU (NEAR_OUTSIDE)
- receiving side = FAR
- real ball Y = 11.59..18.90 BU (FAR_HALF)

## Tracking

Before a component may create the initial trajectory lock it must now pass:

1. selected-ball appearance
2. perspective ball-scale guard
3. active-half / receiving-side guard
4. motion continuity
5. straightness
6. prediction compatibility

Only after that does the existing Top-3 selector run.

## Decision invariant

OUT remains OUTSIDE GRID ONLY.

The active-half guard uses continuous homography coordinates only to reject an
irrelevant bootstrap trajectory. It does not traverse or use an interior grid
to decide IN/OUT.

## Telemetry

- BOOT SIDE REJECTS
- BOOT FLOOR XY BU
- BOOTSTRAP SCOPE
- RUNTIME MODE

Modes:

- NET HALF — true HALF_COURT net-mounted production calibration
- FULL ENG — full-court engineering/regression compatibility
