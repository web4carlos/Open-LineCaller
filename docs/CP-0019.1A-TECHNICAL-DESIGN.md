# CP-0019.1A Technical Design — Offline Automatic Validation Runner

## Goal

Create a reproducible offline validation loop that directly executes the
Open-LineCaller pipeline over a recorded video.

## Separation

Offline validation answers:

    If every frame is available from a file, how accurate is the algorithm?

It does not answer:

    Can the complete system arbitrate correctly from a live camera in real time?

## Components

OfflineFrameIterator
- sequential video decoding
- frame number
- timestamp derived from source FPS

OfflinePipelineAdapter
- stable contract between validation and officiating pipeline

OfflineValidationRunner
- frame loop
- event collection
- prediction persistence
- ground-truth matching
- metrics
- report

EventMatcher
- supports event_id match
- supports frame tolerance fallback

OfflineValidationResult
- video metadata
- generated predictions
- comparisons
- metrics
- processing statistics

## Matching

Preferred:
- exact event_id

Fallback:
- nearest unmatched prediction within configurable frame tolerance

This allows the validation system to work even when prediction events are
generated automatically rather than pre-authored with ground-truth IDs.

## Metrics

The existing CP-0019 metrics remain authoritative:
- automatic accuracy
- coverage
- review rate
- miss rate
- false IN
- false OUT
- average confidence
- average latency

Additional offline runner metrics:
- frames processed
- source FPS
- wall-clock processing time
- effective processing FPS
