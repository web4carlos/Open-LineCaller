# CP-0035.6 — DCF Ball Candidate Selector

This capability moves DCF reasoning before tracker lock.

Old:
YOLO -> highest confidence -> Kalman

New diagnostic path:
YOLO -> ALL candidates -> DCF plausibility scoring -> selected candidate -> Kalman

Current selector scores:
- continuity to predicted ball position,
- apparent size continuity,
- detector confidence.

A high-confidence object far from the expected trajectory can no longer
automatically win.

This capability also includes a frame diagnostic tool that exports every YOLO
candidate for one real video frame, allowing direct inspection of frame 21611.

No production tracker wiring is performed yet.
