# CP-0026.2 — Curvature Bounce Engine

Main change:
Bounce candidates are now scored using the SHAPE of the tracked trajectory.

Score components:
- local trajectory curvature
- vertical reversal strength
- local maximum image-y
- tracker/detector confidence
- RAW observation ratio
- horizontal continuity

New event fields:
- curvature
- bounce_score

The goal is precision over quantity:
fewer bounce events are acceptable if the remaining events align better with
real floor contacts.

This pack still does NOT decide IN/OUT.
