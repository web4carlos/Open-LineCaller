## Purpose

Bind each physical LineCaller camera to explicit regions of the OFFICIAL
outside-only floor grid.

This is designed for low/side mounting near the net, including phone holders
attached near a net post or rigid arm.

## Rule

`CALIBRATED EXTERNAL GRID -> CAMERA OWNERSHIP -> RECEIVING SIDE -> FRAME LOOP`

There is no interior-grid fallback.

## Ownership zones

- FAR_LEFT
- FAR_BASELINE
- FAR_RIGHT
- NEAR_LEFT
- NEAR_BASELINE
- NEAR_RIGHT

A camera may own one or several zones.

At runtime only zones matching the current receiving side are active.
If a camera owns no zone for that side, it scans zero cells (fail closed).

## Corners

Corner cells belong to both adjacent zones. Example:

`FAR_LEFT corner = FAR_LEFT + FAR_BASELINE`

This prevents blind wedges beyond the intersection of a sideline and baseline.

## Mount metadata

Supported mount positions:

- NET_LEFT
- NET_RIGHT
- NET_CENTER
- OTHER

Mount position is metadata. It does not silently invent ownership.
Ownership must be explicit because installation geometry can vary.

## Safety

- Source cells come only from the calibration-owned External Grid.
- No interior cell is created or added.
- Runtime produces a filtered calibration view using the same homography,
  polygons, scale, background and image-up vector.
- Camera routing cannot expand beyond calibration.
