# CP-0030.7 — Multi-Frame Calibration Evidence

Problem:
A single frame may not contain a fully visible court.

Players, net posts, shadows, glare and camera framing may obscure different
boundaries at different moments.

New strategy:

AUTO MULTI-FRAME
    -> analyze several frames
    -> collect valid court hypotheses
    -> reject temporal outliers
    -> aggregate robustly
    -> calculate confidence per outer boundary
    -> GOOD / REVIEW / LOW
    -> Precision User Refinement if necessary

The system never invents certainty when a boundary lacks sufficient temporal
support.

Output calibration mode:
AUTO_MULTI_FRAME
