# CP-0032.4 — Integrated Pickleball Rules Pipeline

Purpose:
Unify the deterministic CP-0032 rule components behind one orchestration
layer before scoring is introduced.

Integrated components:
- Serve legality
- Two-bounce rule
- NVZ / kitchen volley rules
- Rally outcome
- Fault ownership

Pipeline:

OFFICIATING DECISION
        |
COURT SEMANTICS
        |
SERVE / TWO-BOUNCE / NVZ RULES
        |
FAULT OWNERSHIP
        |
RALLY OUTCOME
        |
CONTINUE / RALLY_WON / REVIEW

Safety invariant:
REVIEW is monotonic.

A REVIEW input or uncertain rules event cannot produce a winner.

This capability deliberately does not modify score.
CP-0033 Score Engine will consume trusted RALLY_WON results.
