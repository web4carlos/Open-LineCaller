# CP-0032.1 — Serve Legality + Two-Bounce Rule

Implements two official-rule foundations:

## Serve placement
The server serves diagonally into the correct opponent service court.
The serve must clear the non-volley zone.
A serve touching the NVZ line is a fault.

## Two-bounce rule
The receiving team must let the serve bounce.
Then the serving team must let the return bounce.
After one bounce has occurred on each side, open volley play may begin.

Safety invariant:
Upstream REVIEW remains REVIEW.
