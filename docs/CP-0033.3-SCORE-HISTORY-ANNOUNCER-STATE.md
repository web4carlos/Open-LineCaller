# CP-0033.3 — Score History + Announcer State

Adds two non-vision score presentation/audit capabilities.

## Score History

Append-only snapshots capture:
- sequence
- game number
- event/action/reason
- A/B score
- serving team
- server number
- serving court
- games A/B
- game-over / match-over flags

REVIEW events can be audited while preserving NO_CHANGE.

## Announcer State

Creates a presentation-safe snapshot for a future UI/TTS layer:
- score call
- server
- serving court
- game number
- match games
- last action/reason
- game/match completion

This module generates text only. It deliberately does not perform audio I/O.

Example traditional doubles opening call:
0-0-2
