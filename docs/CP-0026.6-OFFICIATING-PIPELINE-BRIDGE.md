# CP-0026.6 — Officiating Pipeline Bridge

This capability converts Bounce Officiating Gate results into downstream
permissions.

- VERIFIED_BOUNCE -> AUTO_OFFICIATE
- REVIEW_BOUNCE -> GEOMETRY_REVIEW_ONLY + force_review=True
- REJECTED_BOUNCE -> DROP_EVENT

The bridge fails closed: unknown or missing gate decisions are dropped.

This prevents low-quality bounce evidence from becoming an automatic IN/OUT
call while still allowing REVIEW events to be projected onto court geometry.
