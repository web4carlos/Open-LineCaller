# CP-0035.9.4.2 RC8.3 — External Grid Pillow Watcher

Status: EXPERIMENTAL / NOT COMMITTED

## Locked architecture

Calibration owns the external grid.

Runtime order:

1. FRAME
2. PILLOW compares current image against the CALIBRATED reference image.
3. The fixed EXTERNAL GRID is queried.
4. Ball-compatible changed pixels vote for one or more external cells.
5. RC8.3 stops here.

RC8.3 does **not**:
- compare against the previous frame;
- track the ball;
- calculate a path;
- calculate velocity;
- calculate XYZ;
- claim Z0 contact;
- claim BINGO / OUT;
- require DOWN;
- run the UP-after-the-fact confirmation.

The purpose of this gate is only to prove that the already-calibrated,
true-perspective external floor grid can detect local ball-compatible
change frame-by-frame using Pillow.

Production grid visibility remains NO.
