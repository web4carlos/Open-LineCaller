# CP-0018 Sprint 6 User Guide

During a live match, press:

    END MATCH

Open-LineCaller will:

1. Stop live capture
2. Build the match summary
3. Open Match Summary
4. Let you save the match
5. Let you export JSON
6. Return to Home

The summary includes calls, replays, FPS, latency, confidence,
tracking losses, camera, calibration mode and duration.
