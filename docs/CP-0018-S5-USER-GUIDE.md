# CP-0018 Sprint 5 User Guide

When a REVIEW event occurs:

1. LIVE pauses visually
2. REPLAY appears
3. buffered frames play in slow motion
4. if bounce coordinates are available, the view zooms toward that area
5. replay finishes
6. the app returns automatically to LIVE

Replay speed can be set to:
- 1.0x
- 0.5x
- 0.25x
