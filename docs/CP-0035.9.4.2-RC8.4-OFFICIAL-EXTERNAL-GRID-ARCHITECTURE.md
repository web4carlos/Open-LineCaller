# CP-0035.9.4.2 RC8.4 — Official External Grid Architecture
Status: EXPERIMENTAL / NOT COMMITTED

## 1. COURT CALIBRATION
FULL_COURT / HALF_COURT court boundaries.

## 2. EXTERNAL 2D GRID
Create the grid over the exterior area and apply camera perspective.
Each cell keeps polygon/pixels, floor position, expected perspective/scale, background/reference.
The grid belongs to Calibration.

## 3. START GAME
Work only the receiving side, not the whole External Grid.
For each frame, loop active cells one by one.
Use Pillow against calibrated reference and evaluate ball color, size, expected perspective/scale, floor compatibility and Ball Identity.
When one cell is compatible, store only that cell as a Z0 candidate.
The candidate is NOT Z0 yet.
After the fact, if the same ball-compatible evidence appears ABOVE the candidate, the original cell is retrospectively confirmed as Z0.
Then render a soft/diffuse glow on that confirmed floor cell.

Runtime: `FRAME -> ACTIVE GRID CELL LOOP -> PILLOW -> ONE CANDIDATE CELL -> ABOVE -> Z0 -> GLOW`

Not used: path, trajectory, global tracker, XYZ flight resolver, DOWN, multiple visible candidates.
Production: grid invisible; only confirmed floor glow visible.
