# CP-0026.3 — Physical Bounce Contact Validation

Problem discovered during CP-0031 validation:

Court Geometry and Court Semantics were receiving bounce events whose x/y did
not always appear to represent the physical ball-floor contact point.

CP-0026.3 adds a conservative validation layer between Bounce Engine and Court
Geometry.

Input:
- CP-0025 ball_track.csv
- CP-0026.2 bounce_events.csv

Validation:
- local maximum in image y;
- vertical trajectory reversal;
- raw YOLO support;
- local tracker confidence;
- event-to-contact localization shift.

Outputs:
- bounce_contact_audit.csv
- validated_bounce_events.csv

Downstream Court Geometry should consume validated_bounce_events.csv.

This pack does not replace CP-0026.2. It validates and relocalizes its output.
