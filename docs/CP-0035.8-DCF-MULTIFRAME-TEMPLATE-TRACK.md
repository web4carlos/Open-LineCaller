# CP-0035.8 — DCF Multi-Frame Template Track

Purpose:
Track one real pickleball reference image through consecutive video frames
without YOLO.

Flow:
reference ball -> DCF ROI -> multi-scale local matching -> update ROI -> next frame

Key behavior:
- same ball may appear larger/smaller because of perspective,
- scales from 0.50x to 2.00x are evaluated,
- when a frame is missed, DCF search ROI expands gradually,
- no full-frame search is performed in normal operation,
- diagnostic overlay and CSV are produced,
- production tracking/officiating pipeline remains untouched.
