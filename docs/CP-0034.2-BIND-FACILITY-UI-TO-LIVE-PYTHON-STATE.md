# CP-0034.2 — Bind Facility UI to Live Python State

The approved CP-0034 visual surface is now bound to CP-0034.1 live snapshots.

Changes:
- removes the static court array from App.tsx;
- Facility View is populated from GET /api/live;
- counts for courts/live/review/ready are computed from Python state;
- Court Live View follows the selected court across polling refreshes;
- score, call, confidence, geometry, evidence, service, camera and session
  fields come from Python;
- visible bridge online/offline state is included;
- visual language from CP-0034.0 is preserved.

The transport remains polling at 750 ms for this capability. A later capability
may move high-frequency event data to WebSocket/SSE without redesigning the UI.
