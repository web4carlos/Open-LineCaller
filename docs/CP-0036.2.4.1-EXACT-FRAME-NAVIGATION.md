# CP-0036.2.4.1 — Exact Frame Navigation

Purpose: remove mouse/slider precision from real-video validation.

## Wizard controls

- Go directly to an integer video frame.
- Analyze an inclusive exact frame range: FROM ... STOP AT.
- Automatic stop after the STOP AT frame has been processed.
- Left/Right keyboard navigation by one frame.
- Shift+Left/Right navigation by ten frames.
- G focuses the direct frame input.
- Space pauses active analysis or toggles browse playback.

Frame numbers are derived from the Wizard Analysis FPS and video currentTime.
This capability does not modify detection, geometry, projected Z0 signatures,
motion memory, camera ownership, or OUT decision semantics.

## Safety

OUTSIDE GRID ONLY remains unchanged.
The exact-range controller is transport/UI logic only.
