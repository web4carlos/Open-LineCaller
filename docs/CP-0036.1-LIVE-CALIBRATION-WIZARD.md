# CP-0036.1 - Live Calibration Wizard

Status: IMPLEMENTED

## Goal

Remove calibration-file handling from the normal LineCaller user flow.

The engineering console remains available at:

`/engineering`

The normal root application becomes:

`/`

## Guided flow

1. Open installed camera.
2. Capture a clean court/background frame.
3. Click the four outer court corners in order:
   - near-left;
   - near-right;
   - far-right;
   - far-left.
4. Build the OFFICIAL outside-only grid.
5. Put the match ball in view and click its center.
6. Select camera ownership / receiving side.
7. Start LineCaller.

The wizard creates internally:

- `EXTERNAL_GRID_BACKGROUND.png`
- `EXTERNAL_GRID_CALIBRATION.json`
- `BALL_TEMPLATE.png`

under `.linecaller_runtime/live/wizard/`.

The user does not need to browse for these files.

## Replacement ball

`Change Ball` stops the live frame loop temporarily and enters ball-selection
mode again.

The court calibration is preserved.

After the new ball is clicked, LineCaller rebuilds the live runtime using:

- the same OFFICIAL external grid;
- the same clean background;
- the same camera ownership;
- a new locked ball color profile.

This supports a broken/replaced ball during a match without restarting court
calibration.

## Safety invariants

- The wizard calls `ExternalGridCalibrator`; it does not create a second grid
  implementation.
- Interior cells remain excluded.
- Runtime remains `OfficialExternalLiveRuntime`.
- Pose Guard remains before the external scan.
- Camera ownership remains fail-closed.
- A Z0 candidate alone does not become OUT.
- `Change Ball` does not change court geometry.

## Launcher fix

The documented PowerShell command now inserts the repository root into
`sys.path` before Uvicorn imports the app:

```powershell
python tools\run_live_api.py
```

The previous `ModuleNotFoundError: No module named 'linecaller'` is therefore
fixed permanently.
