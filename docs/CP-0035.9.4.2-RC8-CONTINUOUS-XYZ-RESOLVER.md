# CP-0035.9.4.2 RC8 — Continuous XYZ Resolver

## Purpose
Resolve one continuous same-ball state `P=(x,y,z,t)` from the validated RC7.2 image projection before the Rolling Three-Point Z0 predictor is allowed to officiate.

## Inputs
- Ball Identity remains **WHO only**.
- RC7/RC7.1 residual remains **PRESENCE evidence**.
- RC7.2 provides projected center `(u,v)` and apparent image scale.
- Real timestamp `t` is mandatory.
- Court calibration can be `FULL_COURT`, `HALF_NEAR`, or `HALF_FAR`.
- Same-ball continuity from RC5 supplies one trusted runtime anchor.

## Output
`TimedPoint3D(P=(x,y,z), t)` in continuous Ball Units.

## Important
- The mesh/cells do not define the flight curve.
- RC8 does not calculate a complete path.
- Apparent residual size is not assumed to be a literal circle diameter.
- A runtime `scale_gain` absorbs partial residual / blur effects.
- HALF and FULL calibration feed the same XYZ contract; there are not two motion engines.
- RC8 is a resolver/diagnostic gate. Z0 remains downstream in RC6's rolling 3-point predictor.
