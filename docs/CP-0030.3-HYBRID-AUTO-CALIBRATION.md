# CP-0030.3 — Hybrid Auto Calibration

Fixes the regression introduced by CP-0030.2.

AUTO detection order:
1. Blue/cyan surface segmentation.
2. Perspective white-line detection if surface detection is unavailable.
3. Manual calibration remains the UI fallback if both automatic methods fail.

This preserves CP-0030 and CP-0030.1 behavior while adding the surface-aware
strategy for real night footage.
