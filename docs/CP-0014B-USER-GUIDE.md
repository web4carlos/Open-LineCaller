# CP-0014B User Guide

1. Open a video.
2. Press P to request a proposal.
3. Review the proposed box.
4. Press A to accept, R to reject, or draw a corrected box.
5. Enable Auto Advance to move automatically after each action.
6. Confirmed boxes remain protected from future proposal overwrite.

A proposal is assistance only. The saved dataset remains the human-reviewed
canonical annotation.
